# Docs

Background for teammates, judges and coding agents working on Altamyra. Entire Brain indexes this folder, so what is written here grounds every agent's brief and search. Keep it accurate and short.

This repository is public. Use fictional or synthetic data only: no real people, emails, keys or student details.

| File | What it is |
| --- | --- |
| [product-analysis.md](product-analysis.md) | The product as the team defined it: the problem, the nine modules, personas, hard rules, design brief, and what is built today versus designed. |
| [agent-workflow.md](agent-workflow.md) | How agents and humans work in this repo: Brain and Graph first, recording decisions, committing, secrets, data rules, checkpoints and checks before pushing. |
| [policy/bc-iep.md](policy/bc-iep.md) | A sourced summary of the BC IEP and reporting policy Altamyra works within, with exact quotes and how each point shapes the product. |
| [decisions/README.md](decisions/README.md) | Architecture decision records: decisions the team made while building, each backed by commits and Brain memories. |

For setup and the tech stack, see the [repository README](../README.md).
